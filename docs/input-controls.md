# 触屏与手柄操作

Windows 和 Web 使用同一套游戏动作。键鼠、触摸和手柄可以随时切换，界面显示最近使用的设备提示。标题菜单、暂停菜单和快捷操作中均可进入“操作设置”。

## 游戏中

| 功能 | 触屏 | Xbox / PlayStation 手柄 |
| --- | --- | --- |
| 前后推进、左右转向 | 左侧虚拟摇杆 | 左摇杆 |
| 观察视角 | 右侧空白区滑动；攻击按钮也可拖动瞄准 | 右摇杆 |
| 角色多角度切换与环绕旋转 | 右侧观察区双指滑动环绕；快捷操作 → 切换角色视角 / 角色角度回正；标题页可拖动或点按旋转按钮 | R3 切换预设视角；快捷操作可一键回正 |
| 上浮、下潜 | 上浮、下潜按钮 | RB / R1、LB / L1 |
| 加速 | 保持加速按钮 | 保持 L3 |
| 攻击 | 攻击按钮 | RT / R2 |
| 瞄准切换 | 瞄准按钮 | LT / L2 |
| 交互、采集、上下潜艇 | 交互按钮 | A / × |
| 突进 | 突进按钮 | B / ○ |
| 护盾开关 | 快捷操作 → 护盾 | X / □ |
| 快捷操作 | 顶部快捷按钮 | Y / △ |
| 海图 | 顶部海图按钮 | View / Touchpad |
| 暂停 | 顶部暂停按钮 | Menu / Options |
| 声呐、伙伴召回 | 快捷操作 | 方向键上、下 |
| 拉近、拉远第三人称视角 | 快捷操作 | 方向键左、右 |

左右摇杆推进沿用游戏的转向方式，适用于潜水员、坐骑和潜艇。轻推摇杆可以缓慢推进或转向。上浮和下潜有独立按键。

蓝光枪短按攻击发射激光，保持 3 秒后松开发射静滞球；普通武器按下攻击一次，不会因持续按住自动连发。瞄准和远镜均为按下切换。暂停、打开菜单、换武器、上下坐骑或潜艇、失焦或输入取消会取消未发射的蓄力。

快捷操作提供四种武器、远镜、护盾、突进、声呐、无人机、助推器、灯、骑乘、六个坐骑槽位、召回、契约板、制造、料理／图鉴、相机距离、角色外观切换以及角色视角切换／角度回正。键盘也可按 **J** 打开快捷操作，按 **K** 切换角色观赏角度，按住 **鼠标右键**（或 **Alt + 鼠标移动**）进行 360° 环绕观察，用 **方向键**／**`[` `]`**／**`,` `.`** 自由旋转角色偏航、俯仰与横滚角度，按 **鼠标中键** 或 **Home**／**`\`** 回正。键盘 **Ctrl** 下潜，**C** 单独切换护盾。

## 菜单与海图

菜单支持触摸点选、手柄方向导航和确认／返回。进入页面时会选中可操作项，禁用项会被跳过。大菜单在较小屏幕上可滚动。

触摸海图可单指拖动、双指捏合缩放、轻点选择位置或地标；通过“设标点”“清除标点”“跃迁”按钮执行操作。拖动不会自动触发跃迁。

手柄海图使用左摇杆平移、方向键循环已知地标、肩键缩放、A / × 选择中心附近位置、X / □ 切换到操作栏；在操作栏确认标点或跃迁，B / ○ 返回。

## 操作设置

可调整手柄与触屏视角灵敏度、Y 轴反转、摇杆死区、触控大小与透明度。触控显示支持自动、始终显示和关闭；自动模式使用触摸后显示、使用手柄或键鼠后隐藏。偏好保存在本机 Godot 用户数据目录的 `input_settings.cfg` 中。

Web 页面需先点击或触摸以获得焦点，部分浏览器需要按一次手柄按钮才能发现设备。手机和平板建议横屏使用。实机兼容性应使用实际导出的 Web 页面与真实触点、手柄进行验收。
